### Button States
```

   - Background: Blue gradient
   - Shadow: Subtle
   - Text: White
   - Cursor: Pointer

2. Hover State
   - Background: Same gradient
   - Shadow: Enhanced
   - Text: White
   - Transform: Up 3px

   - Background: Same gradient
   - Shadow: Minimal
   - Text: White
   - Transform: Up 1px
```
